## Asif Hossain

I run [ObitO Digital](https://obitodigital.com). Client work is attribution and lead generation; on the side I've been building an options research engine.

Almost everything here is private, so — how I work, rather than what I've shipped.

The hypothesis gets written down before the backtest runs. Not for rigour points; it's the only way I've found to stop myself quietly redefining success after seeing the numbers.

Failures stay in the repo. The best-looking spread I found last year turned out to be a data artifact, and it's written up in the same detail as the things that worked.

I check the thing doing the checking. An LLM scorer of mine gave 100/100 to copy containing a product name that didn't exist. The generator was wrong; the scorer being certain was the actual bug.

Mostly Python: Flask, SQLAlchemy, Postgres, a lot of pytest. Some React. More legacy PHP than I'd like.
